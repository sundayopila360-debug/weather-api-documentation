# Getting Started

This guide explains how to begin using the Weather API.

## Prerequisites

Before using the API, ensure that you have:

- An API key
- Internet access
- A tool for making HTTP requests

## Base URL

https://api.example.com/v1

## Example Request

GET /weather?city=Abuja

## Example Response

{
  "city": "Abuja",
  "temperature": 28,
  "humidity": 65,
  "description": "Partly cloudy"
}
